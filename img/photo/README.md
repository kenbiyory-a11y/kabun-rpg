# img/photo — 旅の写真（せかい の「ドイツ・シンガポール・ドバイ」の問題で使う）

問題（js/quiz/trip.js）は `[img:photo/<名前>.jpg|絵文字]` で写真を指す。ファイルが無いときは `|` の後ろの絵文字が出るので、無くても遊べる。
家族で撮った写真に差し替えてよい（横長〜正方形、640px くらいの JPEG。顔が写ったものは公開リポジトリに入れない）。
