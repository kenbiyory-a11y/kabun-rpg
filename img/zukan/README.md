# img/zukan — ずかん の しゃしん と かげ

- `<id>.jpg`：つかまえた ときと ずかん に出る 写真（横 560px くらい、JPEG）。
- `<id>_cut.png`：であった ときの かげ（背景を抜いて 黒く塗った PNG、256px）。無い生き物は 絵文字を 黒くして 出す。
- id は `js/zukan.js` の id と同じ。写真を置いたら zukan.js の その行に `img:true`（かげ も あれば `cut:true`）を付ける。
- 出典とライセンスは CREDITS.md。自由に使える写真（CC0 / パブリックドメイン / CC BY / CC BY-SA）だけを使う。図鑑や 検索で出た画像は 使わない。
- sw.js の SHELL には入れていない（見たときに キャッシュされる）。オフラインで まだ見ていない写真は 絵文字で出る。
- 作り方：候補集め・選定・切り抜きの スクリプトは リポジトリ外（作業用フォルダ）。Wikimedia Commons の API で ライセンスを絞って検索し、rembg で背景を抜いた。
