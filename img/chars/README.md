# キャラの絵の置き場所

ここに **背景が透明の正方形 PNG** を、下の名前で置くだけで、ゲームの絵文字がその絵に置き換わります。
無いものは絵文字のまま出るので、できたものから1枚ずつ置けます。置いたあとは `sw.js` の `VERSION` を上げて commit / push すると、スマホにも届きます。

## 画像の条件
- 正方形、256×256〜512×512 px、背景は透明（PNG）。1枚 200KB 以下が目安。
- キャラは正面か少し斜め、全身、まん中に大きく。足元に影は付けない（ゲーム側で影を付けます）。
- 向き：カブーンは右を向く、相手（かべ・ぬし）は左を向くと、バトルで向かい合います。

## AI で作るときのコツ
- 全キャラで同じ書き出しの指示文を使うと作風がそろいます。例：「ゲームボーイ時代のレトロゲーム風ドット絵、カラー、16色くらい、太い黒い輪郭、2.5頭身、正面、全身、背景は透明、1体だけ、やさしい表情、4歳の子ども向け」＋そのキャラの説明。
- 背景が白で出てきたら、透過にできるツール（画像編集アプリの「背景を消す」など）で消してから置きます。
- 家族の絵は、実際の顔写真ではなく AI のキャラ絵にしておくと、このフォルダごと公開リポジトリに置いても安心です。写真を使いたい場合は言ってください（端末の中だけに保存する形にします）。
